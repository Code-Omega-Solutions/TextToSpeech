# Corresponding source offer for container images

Code-Omega-Solutions offers to provide any recipient of a newly built
TextToSpeech container image that includes this offer with the complete
corresponding source code for the image's third-party components whose licenses
require source availability. This includes the exact source versions,
applicable patches, build and installation scripts, and other materials
required by those licenses, including relinkable materials where applicable.

This offer is valid for at least three years after the date the corresponding
image version was first distributed. To request source, email
patrik.gfeller@code-omega.ch with the image tag or digest. Electronic copies
will be provided without charge; physical media may be charged only for the
reasonable cost of physically making and delivering the source copy.

The offer applies to any recipient of a covered image, not only the original
recipient. The runtime package inventory is included in the image at
`/usr/share/doc/texttospeech-frontend/RUNTIME-PACKAGES.txt`. Debian package
copyright and license notices are retained under `/usr/share/doc/*/copyright`.
