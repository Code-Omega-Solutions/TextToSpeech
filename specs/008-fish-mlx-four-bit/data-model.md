# Data model: Fish 1.5 MLX candidate

## Approved origin

Exact source revision and tree digest, checkpoint file digests, codec digest, runtime binding, model and source terms, and reference catalog. Existing manifests remain unchanged.

## Derived artifact

Isolated semantic weights, configuration, tensor names and shapes, packed 4-bit group size, excluded layers, source checkpoint digest, converter/runtime versions and hashes. The candidate approval binds all files and conversion inputs; an unreviewed, changed, incomplete or incompatible candidate must not start.

## Worker state

Existing managed lifecycle: absent, starting/preloading, ready/busy, stopping, cooldown or cleanup-unverified. The candidate must not bypass existing admission, owned-process cleanup, timeout or fallback transitions.
