Use a fenced code block to anchor a small, relevant excerpt in `plan.md` or `tasks.md`. For existing code, use `<language> <repository-relative-path>:<first>-<last>` and copy those source lines exactly. For code not written yet, use `<language> sketch <repository-relative-path>` and show the proposed code.

Optionally add `hl=<line-or-range,...>` to highlight lines in the excerpt. Immediately after the closing fence, add up to 3 `pin <line>: <reason>` lines for important lines; pin numbers are source line numbers for a citation and 1-based sketch lines for a sketch.

Keep sketches to 12 lines or fewer. Use paths inside the repository, without `..` or absolute paths.
